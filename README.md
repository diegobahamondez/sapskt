# SAPSKT - DJ Webpage

Repositorio para la página oficial de **SAPSKT** (DJ & Music Producer).

## Estructura de carpetas
- `/assets`: Carpeta destinada a imágenes, fotos y recursos multimedia.
- `index.html`: Página principal.
- `style.css`: Estilos visuales de la página.

## Deployment en GitHub Pages
Este sitio está preparado para hospedarse en GitHub Pages.
